# Weirdest Job Title

An entry for the make.fun bounty **"Weirdest Job Title: Blind Judge Showdown"** — one job title, 60 characters or fewer, judged head-to-head by a blind judge model that picks the weirder, funnier one.

The entry:

> Lead Lighthouse Keeper for a Landlocked Town

A perfectly respectable job — guarding ships from the rocks — in the one place on Earth where no ship will ever come. The lighthouse still stands, the keeper still keeps it, and the sea is nowhere to be found.

## How to run

```bash
python3 main.py
```

This prints the entry line to stdout and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
